# 知页阅读器

在本机浏览器中阅读 Markdown 笔记，使用公式、全文搜索、页内目录、高光和批注。

## 启动

在项目根目录运行 `python3 阅读器/launch.py`。macOS 也可以双击 `打开阅读器.command`；Windows 使用 `py -3 阅读器/launch.py`。

启动器会复用同一工作区已运行的服务，默认从 `http://127.0.0.1:8765` 开始尝试可用端口。它在后台运行，重启电脑后需重新打开。需要明确管理服务生命周期时，使用 `python3 阅读器/server.py` 在前台运行，按 `Ctrl+C` 停止。

也可指定自己的文档根目录、空闲端口和阅读数据目录：

```bash
python3 阅读器/server.py --root ./个人资料 --port 8766 --data-dir ./阅读器/data
```

不同书库应使用不同的数据目录。不要把服务转发到公网。

## 阅读

- `⌘K` / `Ctrl+K` 搜索标题和正文，包括中英文术语。
- 选中正文后选择暖黄、鼠尾草绿或浅紫色高光，随后可添加批注。
- 右侧查看本页目录与高光；左侧“我的高光”查看全部标记。
- `Aa` 调整字号、主题与宽度；`F` 切换专注阅读。
- 文档目录约每 12 秒自动检查变化，也可手动刷新。
- Markdown 链接在阅读器内跳转，PDF 等原件在新标签页打开。

行内公式使用 `\(...\)`，独立公式使用独占行的 `$$` 或 `\[...\]`。原始 HTML 作为文本处理，公式按 KaTeX 支持的语法渲染。

## 保存与恢复

默认状态位于 `阅读器/data/阅读记录.json`，包含高光、批注、阅读位置与外观设置。状态与笔记原文分开保存，并默认被 Git 忽略。高光面板上的下载按钮可导出完整备份。

恢复前先停止本工作区的服务。使用前台方式启动的服务按 `Ctrl+C` 停止；后台服务可查看 `阅读器/data/service.json` 中的进程编号，在系统进程管理器中确认并结束对应阅读器进程。用备份 JSON 替换状态文件后重新启动。

修改正文后，高光会按选文和前后文重新定位。选文消失或有无法区分的重复内容时，保留批注并显示无法定位，不猜测位置。

## 运行与开发

运行需要 Python 3.9+。前端使用原生 JavaScript；随附 Markdown、公式库和公式字体，读取本地笔记无需联网。外部网页和远程图片仍访问原地址。

开发检查需要 Node.js 20+。在本目录运行：

```bash
npm ci
npm test
```

源码入口为 `server.py`、`web/app.js`、`web/render.js` 和 `web/anchors.js`。依赖版本与许可见 [第三方资源](../THIRD_PARTY_NOTICES.md)。
