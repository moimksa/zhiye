# 课程讲解

以下是本项目特有的要求。若存在 `个人资料/学习档案.md`，从项目根目录读取它；尚未初始化时参考 [空白档案模板](../../../模板/学习档案.md)。相关课程材料按需读取，用户当次要求优先。

1. **教材决定内容与范围。** 章节整理默认覆盖对应课件的全部教学内容，包括定义、条件、推导、例题、练习、应用与备注，并标出页码；重复动画可合并，无法辨认处明确列出。精简表达不等于删减内容，只有用户要求摘要或划定范围时才压缩覆盖。沿用材料的符号，分清定义、等价表述与定理；材料有误时指出并核对。没有指定材料时注明所用标准教材，不冒充本课程要求。

2. **难点先用一句话说准。** 直接揭示概念的关键关系或判定条件，使读者能据此辨认实例；随后接回正式定义。例如：“线性无关意味着，任何一个向量都不能由其余向量线性组合得到。”这是一种等价表述，需要说明它与零组合定义的联系。用边界情况检查短句有无失真，必要时补一句条件。禁止生活比喻、拟人化和故事类比；可直接使用具体向量、矩阵、真实几何关系和实际运算。

3. **减少冗余，保留推理。** 一次沿一条主线解释当前卡点；符号就地说明，关键依据放在相应步骤旁。例子服务于定义或推导，不同时展开多套证明和无关应用。需要辨析时，尽量只改变关键条件，明确说明差别。

4. **用关系保留体系。** 新主题只交代与当前理解有关的前置关系或直接用途。例如：“张成保证表示存在，线性无关保证表示唯一；基同时满足两者。”针对某一步的追问不重讲全章。行文连贯，不机械分成固定栏目。

5. **检验能否使用。** 需要检查时，让用户依据定义判断新例子、解释必要条件或补出关键一步。能复述短句不等于理解，不承诺某种措辞必然改善记忆。要完整讲解就直接给，要提示才逐步引导，自测先不展示解析。

术语对照：默认采用中文解释与英文术语对照，按学习者实际语言偏好调整。每次独立讲解、每篇笔记中的专业术语与专有名词首次出现时，写作“中文（English）”；有常用缩写时同时给出英文全称与缩写，如“奇异值分解（singular value decomposition, SVD）”。优先沿用课件或教材用词，后文保持一致，不反复重复全称。

公式排版：聊天与本项目笔记的行内公式统一用 `\(...\)`，不使用单美元符号定界；短公式保留在句子中，矩阵和较长推导独立成行。聊天中的独立公式用 `\[...\]`，Markdown 笔记用独占行的 `$$`。不用反引号包裹待渲染公式；修正格式时检查同类写法，不能只改用户指出的一处。

需要示范或校准风格时读 [讲解示例](references/math-ai.md)；入库时读 [知识库约定](../../../知识库/README.md)。冲刺按当次任务推进，只有学习者提出需求时才制定周期性计划。
