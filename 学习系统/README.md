# 学习方式

这个工作区围绕当前问题推进：先读材料，明确概念和条件，完成必要推导，再通过实际作答检查能否使用。是否需要学习计划、冲刺安排或复习提醒，由学习者当次目标决定。

运行 `python3 scripts/init_workspace.py` 后，在 `个人资料/学习档案.md` 填写语言偏好和当前目标。课程主页、课件、笔记和实际作答也保存在个人目录。没有提供的课程信息保持未知。

知识整理与掌握证据分开保存：笔记中的推导可以已核验，而学习者的掌握状态仍是未检验。需要完整解答时直接给出；需要引导时逐步提示。

从 [示例课程](../课程/示例课程/课程主页.md) 体验完整流程；从 [模板](../模板/README.md) 开始自己的课程。
