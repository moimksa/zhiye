# 数据与发布说明

## 公开内容

公开发行版由明确选取的文件组成：阅读器源码及随附依赖、通用协作规则、空白模板，以及一个自编的“投影与最小二乘”案例。案例包含笔记、自测和参考解析，不包含任何人的实际答卷或能力评估。

## 本机内容

| 内容 | 默认位置 | 是否进入 Git |
| --- | --- | --- |
| 学习档案、个人笔记、课程原件、作答和备考安排 | `个人资料/` | 默认忽略 |
| 高光、批注、阅读位置与主题 | `阅读器/data/阅读记录.json` | 默认忽略 |
| 启动日志与进程信息 | `阅读器/data/` | 默认忽略 |
| 通用模板与自编演示内容 | `模板/`、`知识库/`、`练习/` 等公开目录 | 跟踪 |

初始化工具只复制空白模板，不读取旧学习目录、不上传资料，也不覆盖已有文件。阅读器的书库可以显示 `个人资料/` 内的笔记，Git 忽略规则只控制版本管理。

## 数据流

阅读器不调用模型接口，不含分析统计、遥测或自动同步。浏览器与本地 Python 服务交换文档和批注。打开外部链接或加载自己笔记中的远程图片会访问相应网站。外部 AI 助手对资料的访问和传输由所选服务决定。

## 再次发布前

先检查暂存文件，再运行 `python3 scripts/check_public.py`。检查脚本覆盖常见的密钥模式、个人目录、联系方式、绝对用户路径和本地文档链接；它无法理解全部自然语言隐私，也不判断材料的再分发权。

`.gitignore` 不会移除已经提交过的资料。如果自己的 fork 中已经跟踪私人内容，应先停止公开推送，处理仓库与历史，再重新发布。公开仓库中的初始模板保持为空；自己的填写结果保存到个人目录。
