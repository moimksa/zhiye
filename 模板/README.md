# 可复用模板

模板用于减少整理成本，按实际需要选用和删减。请保留模板本身，将内容复制到 `个人资料/` 下的对应课程、知识库、练习或备考目录中再填写。

| 模板 | 何时使用 |
| --- | --- |
| [学习档案](学习档案.md) | 保存自己的目标、材料和语言偏好 |
| [学习记录](学习记录.md) | 记录真实作答和使用的帮助 |
| [当前重点](当前重点.md) | 明确当次目标与下一步 |
| [课程主页](课程主页.md) | 接入一门新课程或整理现有课程入口 |
| [概念笔记](概念笔记.md) | 保存可跨题目复用的概念、推导或方法 |
| [练习与错题](练习与错题.md) | 整理具体题目，以及有实际作答依据的错因 |
| [实验记录](实验记录.md) | 保存 AI 或数学实验的假设、运行条件和真实结果 |
| [考试准备](考试准备.md) | 围绕一次考试或当前冲刺确定范围和优先级 |

“待填写”表示需要真实材料补充，不能靠猜测补齐。不存在的字段可删除；没有结果的实验保留“未运行”；没有作答的问题保留“未检验”。
